# SalonOS

Multi-tenant SaaS/PWA для салонов красоты.

## Каноническое MVP-ТЗ

Полное зафиксированное техническое задание находится в:

**docs/MVP_TZ.md**

При разработке сверяемся с этим файлом. Он специально вынесен из корня приложения, чтобы не мешать проекту.

## MVP

SalonOS позволяет салону без изменения кода:

- создать свой салон;
- настроить бренд и одну из 4 тем: Light / Dark / Soft / Modern;
- добавить мастеров и услуги;
- назначить услуги мастерам;
- настроить расписание и исключения;
- получить публичную страницу по slug;
- принимать онлайн-записи;
- видеть записи и клиентов в админ-панели;
- отправлять опциональное Telegram-уведомление о новой записи.

## Архитектура

```
PWA
  |
  v
FastAPI
  |
  +---- PostgreSQL (production)
  |
  +---- SQLite (local/demo)
```

## Multi-tenant

Каждая бизнес-сущность принадлежит `salon_id`. Backend определяет salon_id из авторизованной сессии, а не из входного параметра клиента.

## Локальный запуск

1. Создать виртуальное окружение.
2. Установить зависимости:

```bash
pip install -r requirements.txt
```

3. Скопировать `.env.example` в `.env` при необходимости.
4. Запустить:

```bash
uvicorn backend.app:app --reload
```

Открыть `http://127.0.0.1:8000`.

По умолчанию для локальной разработки используется SQLite. Для production задаётся `DATABASE_URL` PostgreSQL.

## Не входит в MVP

AI, онлайн-оплата, бухгалтерия, склад, зарплаты, сложная CRM, лояльность, нативные приложения и сложная аналитика.
