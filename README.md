# SalonOS

Multi-tenant SaaS PWA для салонов красоты.

## Идея

Один код приложения обслуживает много салонов. Данные салонов хранятся в PostgreSQL и разделяются через обязательный `salon_id`.

- GitHub — только исходный код.
- PostgreSQL — клиенты, мастера, услуги, расписание и записи.
- PWA — клиентская и административная часть.
- Backend — API и бизнес-логика.
- AI assistant — отдельный слой, который работает только через защищённый API.

## Архитектура

```
PWA
  |
  v
FastAPI backend
  |
  +---- PostgreSQL
  |
  +---- AI tools/API
```

## Multi-tenant правило

Каждая бизнес-сущность принадлежит салону через `salon_id`. Backend никогда не принимает `salon_id` от клиента как источник прав: после авторизации он определяется из сессии пользователя.

## Локальный запуск

1. Создать виртуальное окружение.
2. Установить `requirements.txt`.
3. Скопировать `.env.example` в `.env`.
4. Запустить:

```bash
uvicorn backend.app:app --reload
```

Открыть `http://127.0.0.1:8000`.

## Переменные окружения

См. `.env.example`.

## Этапы

1. Базовая PWA + backend.
2. Авторизация и роли.
3. Multi-tenant PostgreSQL.
4. Клиенты / мастера / услуги / расписание.
5. Записи и защита от двойной записи.
6. Уведомления.
7. Кастомизация салона.
8. AI-помощник.
9. Платежи и тарифы.
